# Reference

Use Reference to configure a building block, look up its methods and observables, or check who owns its resources. For a walkthrough that combines these pieces, follow the [Tutorial](../concepts/README.md).

- [Event Sourcing](../event-sourcing/README.md): design events, projections, session boundaries, and replay-safe live work.
- [@katakit/core](core.md): framework-independent runtime, plugin composition, and built-in event history.
- [Built-in event log](core.md#built-in-event-log): replayable in-memory history.
- [@katakit/persistence](plugins/persistence.md): append new events to application-owned storage.
- [@katakit/react](react.md): React runtime hooks and DevTools for observable deliveries; workbench plans are documented separately.
- [@katakit/transcript-ingestion](plugins/transcript-ingestion.md): build live conversations from supplied text.
- [@katakit/transcription](transcription.md): local speech recognition today; the adapter vision extends beyond audio transcription.

For a runnable application, choose a [Starter](../starters/README.md). Its overview explains how a starter differs from a plugin or a feature demo.
