# Local transcription

Record speech in your browser and read it as conversation turns. Compare Moonshine's
live provisional text with Whisper's chunked transcription, switching models between
recordings. Audio stays on your device; models download on first use.

This example demonstrates local microphone capture, model selection, and connecting
recognition callbacks to Katakit transcript ingestion and a React transcript view.

See [AGENTS.md](AGENTS.md) for setup, code organization, customization, and checks.
Those instructions are for both people and coding agents.
