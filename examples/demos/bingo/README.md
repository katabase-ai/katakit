# Conversation bingo

Speak into your microphone and watch matching phrases light up a bingo card.
Choose a word list, correct squares by clicking them, and follow the live transcript.
Speech recognition runs in your browser; the first use downloads a model.

This example demonstrates how to connect local speech recognition to transcript
ingestion, derive game state from logged events, and display it in React.

See [AGENTS.md](AGENTS.md) for setup, code organization, customization, and checks.
Those instructions are for both people and coding agents.
