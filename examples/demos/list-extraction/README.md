# List extraction

Dictate locally, configure one or more lists, then choose **Extract lists** to send finalized
speech to a host-supplied model. Edit or hide results, inspect their exact transcript evidence,
and copy the lists as Markdown. A labeled sample works without a microphone or model.

The demo records rules, transcript turns, accepted items, and edits as events; requests only run
on demand. Audio stays on the device. Recording upload is not supported.

See [AGENTS.md](AGENTS.md) for independent setup, model requirements, code organization,
customization, hosting, and manual verification.
