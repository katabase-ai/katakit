# Changelog

## 0.2.0

- Inspect observable deliveries on a timeline with `KatakitDevTools`. Styles ship compiled.
- Start a runtime from React with `useKatakit` or `useKatakitInit`.
- The former placeholder now requires `@katakit/core` `^0.2.0`, React 19, and React DOM 19.

## 0.1.0

- Initial placeholder package for future Katakit-specific React APIs.
- Provide an empty ESM entry point and TypeScript declaration; React bindings and DevTools are not implemented.
